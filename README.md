# Hunde Duell

Eine mobile-optimierte Webapp, in der zwei Hunderassen gegeneinander antreten. Nach jedem Klick bleibt der gewählte Hund im Rennen, der andere wird ersetzt. Nach 10 Entscheidungen bleibt der finale Favorit mit dem Text "Mein Liebling" stehen.

## Lokal starten

Die App ist statisch und kann direkt im Browser geöffnet werden:

```text
index.html
```

Für GitHub Pages reicht es, die Dateien in ein Repository zu laden und Pages auf den Branch mit diesen Dateien zu setzen.

## Bildquelle

Die App lädt Bilder über die öffentliche Wikimedia-Commons-API. Für faire Vergleiche nutzt sie je Runde denselben Modus: entweder erwachsene Hunde oder Welpen.
